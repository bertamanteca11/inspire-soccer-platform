# Phase 3 — Session Standouts

Adds a mobile-first Session Standouts workflow for the admin:
- Manual Top 2 performers per training/match.
- Manual Bottom 2 / follow-up players per training/match.
- Four unique players enforced per session.
- Optional staff notes.
- Historical storage by session in Supabase.
- Admin-only editing, authenticated read access.
- New Standouts entry under More.

## Before running
Run `inspire-soccer-fase-3-supabase.sql` in Supabase SQL Editor.
Copy your existing `.env` into this project, then run `npm install` and `npm run dev`.
